# LqMusic — instruções para agentes

Quando o usuário pedir para instalar, configurar ou atualizar este app numa TV, leia `docs/INSTALACAO-ASSISTIDA.md` e conduza a instalação no computador local. A abertura deve pedir somente o IP da TV, o IP local do computador/notebook e se o Developer Mode está ativo, reutilizando respostas já dadas. Descubra SDK, rede e perfis pelas ferramentas locais; não peça ao iniciante caminhos, nome de perfil, DUID ou versão do sistema como formulário inicial. Essa é uma tarefa de instalação Samsung Tizen, não de programação. Confira os pré-requisitos disponíveis antes de perguntar e execute as etapas já autorizadas, pedindo apenas informações e ações humanas que faltarem.

Para alterações de código, consulte `docs/COMPILAR.md` e preserve a base original e as licenças. O procedimento de instalação só deve ser executado quando solicitado pelo usuário; abrir o repositório para leitura ou desenvolvimento não autoriza instalar software.
