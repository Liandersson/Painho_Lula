# Painho Lula — web app Tizen

O `config.xml` inicia `full-app/index.html`, o app React original adaptado para Tizen. Compile com `bash web/tizen-tv/build-web-app.sh`; não publique certificados nem assinaturas geradas localmente.

Consulte [instalação](../../docs/INSTALAR-NA-TV.md), [compilação](../../docs/COMPILAR.md), [validação](../../docs/VALIDACAO.md) e [publicação](../../docs/PUBLICAR.md).

Versão de desenvolvimento: 1.3.0. Compatibilidade mínima configurada: Tizen 9.0. Base usada no desenvolvimento: Samsung UN50CU7700GXZD com firmware atualizado. Outras TVs precisam de validação própria.

Código/design originais do BitChord preservados; veja LICENSE e NOTICE.md na raiz. Os arquivos antigos index.html/app.js/styles.css permanecem como histórico do protótipo; o conteúdo ativo é o web app completo em full-app.
