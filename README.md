# Painho Lula

**A straight copy of BitChord, made for personal use on Android.**

Painho Lula is an open-source music app for Android. It is a direct copy of
BitChord, renamed and kept for my own private use. All credit for the original
design and code goes to the BitChord project and its contributors.

## About

- Same features as the original BitChord (see the original repository)
- Android only
- Built for private, personal use
