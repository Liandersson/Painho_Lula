# Painho Lula

**A straight copy of BitChord, made for personal use on Android.**

Painho Lula is an open-source music app for Android. It is a direct copy of
BitChord, renamed and kept for my own private use. All the credit for the
design, the interface, and the code goes to the original BitChord project.

## About

- Clean, modern, minimalist music player
- Android only
- Built for private, personal use
