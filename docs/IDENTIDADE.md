# Identidade LqMusic

Nome público: **LqMusic**. A arte roxa foi fornecida pelo mantenedor e redimensionada para os ícones; não foi redesenhada.

A versão TV 1.3.1 conserva o application ID `painholula.PainhoLulaTV`, o package `painholula`, o widget ID e as chaves de armazenamento anteriores. São identificadores internos de continuidade: alterá-los criaria outra instalação ou perderia o acesso ao histórico. Eles não são o nome exibido ao usuário. Use o mesmo certificado de autor para atualizar.

O endereço GitHub permanece temporariamente `Liandersson/Painho_Lula`; a renomeação do repositório foi adiada pelo mantenedor. Links continuam apontando ao endereço existente. Fontes Android/desktop preservadas receberam textos/ícones de marca; esta release distribui e valida somente o web app Samsung Tizen.

Os créditos BitChord, copyright e licenças permanecem preservados.
