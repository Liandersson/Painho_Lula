# Contribuir com Painho Lula TV

Este repositório distribui o web app para Samsung Tizen TV. Abra issues e pull requests neste repositório, descrevendo o problema, modelo da TV, versão Tizen e como reproduzir.

Para desenvolver, veja [compilação Tizen](docs/COMPILAR.md). Para instalar, veja [tutorial Samsung TV](docs/INSTALAR-NA-TV.md). Faça mudanças pequenas e informe os testes realizados; diferencie testes automatizados de testes físicos na TV.

Preserve as licenças, créditos e módulos originais. Não envie certificados, senhas, cookies, arquivos de configuração pessoal ou pacotes assinados com chaves privadas.
